## 2. Locked Decisions

**D1 — Scope:** ทำ 3 อย่างใน PR เดียว: suppressedSenders UI + filterKeywords + gmailLabel
**D2 — Default = empty:** ทุก field เริ่มว่าง — ไม่มี preset, ไม่มี required filter
**D3 — Gmail Label:** text input (พิมพ์ชื่อ label เอง) + inline warning + dropdown (v2)
**D4 — Keyword logic:** OR ภายในลิสต์ + AND กับ label (ถ้ามีทั้งคู่)
**D5 — PDF text extraction (ฟรี):** v1.5 — digital PDF → extract text → ไม่ต้องใช้ AI vision

## 3. v2 Roadmap — Self-learning (CEO vision)

- **v1.5:** `pdf-parse` → extract text จาก digital PDF ฟรี → ไม่ต้องส่ง Gemini Vision
- **v2:** confirmed expense drafts → auto-suggest sender ให้เพิ่ม filterSenders; rejected → auto-suggest suppressedSenders
- **v3:** PDF layout template learning — หลัง N parses จาก sender X → รู้ field position → extract ไม่ต้องใช้ AI เลย
