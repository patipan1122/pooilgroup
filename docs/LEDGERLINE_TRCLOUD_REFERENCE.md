## ส่วนที่ 4 — กฎการส่งเอกสารเข้า TRCloud

| กฎ | รายละเอียด |
|---|---|
| **บริษัท** | JPS GROUP เท่านั้น (company_id=45) ห้ามส่งไป company อื่น |
| **รูปแบบเอกสาร** | `JPS_AP` (custom format ของ JP Sync) |
| **VAT** | `tax_option=in` (VAT รวมใน ราคา = VAT-inclusive) |
| **สถานะ** | `draft/รอตรวจสอบ` เสมอ — นักบัญชี approve ใน TRCloud ก่อน post |
| **ประเภทการชำระ** | `Cash[AP]` ถ้าจ่ายแล้ว / `Deposit[AP]` ถ้ายังค้างจ่าย |
| **สาขา (branch)** | ส่งใน field `project` = รหัสสาขาใน TRCloud |
| **GL บัญชี** | ส่งใน field `acc_code` ของแต่ละบรรทัด |
| **บล็อกอัตโนมัติ** | สาขาที่ยังไม่ได้ตั้งค่า TRCloud → ระบบบล็อกไม่ให้ส่ง |
