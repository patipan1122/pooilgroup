## 1. 🎯 Goal & Success Metrics
**เป้าหมาย:** เปลี่ยนการแจ้งงานแก้แบบกระจัดกระจาย (แคปทีละรูป อธิบายทีละอัน) → เป็น **เดินดูทั้งแอป ปักหมุดคอมเมนต์ข้ามหลายหน้าในรอบเดียว → กดเสร็จ → ได้รายงานชุดเดียวส่งให้ Claude แก้รวดเดียว**
- **Success metric:** รอบ feedback 10 จุด จาก ~40 นาที/10 รายงานแยก → ≤10 นาที/1 รอบ · ≥80% ของหมุดมี URL+element ที่ใช้แก้ได้ทันทีโดยไม่ต้องถามซ้ำ
- **Definition of Done:** super_admin กด "คัดลอกให้ Claude" ได้ markdown ที่ระบุ หน้า+element+คอมเมนต์ ครบทุกหมุด

## 3. 🗣️ Debate Highlights (สิ่งที่ทีมเถียงกัน)
1. **Devil ท้าทั้งฟีเจอร์** ("มี /bugs + แชต Claude อยู่แล้ว · html2canvas โรงละคร") → ยอมถอย 3/5 ข้อ เมื่อ **Domain Expert** ชี้ว่าภาพคือ "ของแถม" · **structured target (URL+selector+innerText+coords%) คือของจริง** + **End User ยืนยันอยากได้ประสบการณ์ roaming pin จริง** (batch อย่างเดียวไม่พอ). สรุป = **build-lean**.
2. **Capture: html2canvas vs snapdom** → Domain Expert ชนะ: **snapdom** (html2canvas พังกับ Tailwind oklch/ฟอนต์ยุคนี้) · ถ่าย **1 ภาพ/หน้า** ไม่ใช่ทุกหมุด · lazy-load เฉพาะตอนเปิดโหมด · **best-effort ห้ามบล็อกการเซฟหมุด**.
3. **Data model: extend bug_reports (Architect R1) vs 2 ตารางใหม่ (SA)** → SA ชนะ: ตารางใหม่ 2 ตัว ไม่ทำ index/หน้า /bugs เดิมรก · กดเสร็จสร้าง 1 แถวใน bug_reports (consolidatedReportId) → ยังต่อยอดระบบบั๊กเดิม.
4. **Draft persistence** → hybrid: เซฟหมุดลง DB ทันที (ปิดแท็บไม่หาย) · localStorage เก็บแค่ sessionId เบาๆ.
5. **PDPA** (QA) → ยอมรับความเสี่ยง + กันชั้น (TTL 30 วัน · export เฉพาะ super_admin กดเอง · consent notice). CEO เซ็นรับ.

## 5. 🔗 Integration Map
- **bug_reports** (เดิม): ไม่ ALTER · กดเสร็จ INSERT 1 แถว (status 'new') → โผล่ใน /bugs.
- **AI button** ([ai-chat.tsx]): +ปุ่ม "เริ่มโหมดติชม" ถัดจาก "แจ้งบัคหน้านี้" (gate admin-tier + flag).
- **admin-shell**: mount `<PinpointProvider>` (lazy, admin-tier+flag) · +nav "ติชม (Pinpoint)" (super_admin).
- **R2**: ใช้ `/api/r2/sign` เดิม · key ใต้ `users/<id>/` (กันแนบภาพคนอื่น).
- **Role**: `isAdminTier` คอมเมนต์ · `isSuperAdmin` รีวิว/export · gate ทั้ง UI + server action.
- **RLS**: mirror bug_reports (`current_org_id()`/`is_super_admin()`).

## 6. 🧩 Feature Spec (MoSCoW)
- **Must:** roaming pin overlay ข้ามหน้า · pin = URL+selector+innerText+coords%+comment เซฟ DB ทันที · snapdom 1 ภาพ/หน้า best-effort · session bar (ปักหมุด/เลื่อนดู/ทั้งหมด/พัก/เสร็จ) · กดเสร็จ→ใบสรุป /bugs · review page + "คัดลอกให้ Claude" markdown (super_admin) · org+role gate.
- **Should:** แท็กด่วน · สถานะแก้แล้ว (reuse fixedAt/fixedCommitSha) · resume paused session · element pin + whole-page pin.
- **Could:** ส่งเข้า LINE กลุ่มช่าง · per-pin fixedCommitSha back-link.
- **Won't (v1):** voice STT · realtime co-annotation · auto-redact PII.

## 7. ⚠️ Risks (Top 5)
1. snapdom ภาพเพี้ยน/ว่างบางหน้า → mitigated: best-effort, หมุดเซฟแม้ภาพล้ม.
2. selector เปราะหลัง refactor → mitigated: เก็บ innerText+role+rect เป็น fallback.
3. R2 บวม → mitigated: webp q0.7 + cap 1600px + 1 ภาพ/หน้า + TTL 30 วัน.
4. PDPA (PII ในภาพ) → mitigated: super_admin export เอง + TTL + consent + CEO รับความเสี่ยง.
5. overlay บล็อกการกดหน้าจริง → mitigated: toggle ปักหมุด/เลื่อนดู, trap เฉพาะตอน placing.
