## §1 · Executive summary

The hub launches 12 programs but its mobile UX has 3 real problems and one confirmed bug:

1. **🔴 BUG — the accounting program (ระบบบัญชี / LedgerLine) is missing from the launcher.** It is `status:"active"` in `lib/modules.ts:868-878` and reachable at `/ledger`, but `app/(admin)/home/page.tsx:253-329` renders only 11 cards (cashhub…fuelos) — there is no `canSee("ledger")` block. The owner literally cannot open accounting from the home screen. **Fix = ~8 LOC, no migration, no env.** All 8 personas flagged this as the #1 item.
2. **🔴 UX — the hero eats the whole first screen.** Greeting + 2 drifting blur blobs + `mb-14 sm:mb-20` push every program below the fold; with `rounded-3xl p-6/p-7 text-2xl/3xl` cards + `min-h-[60px]` descriptions, only ~1.3 programs show per phone screen → scrolling through 12 is painful. This is the "make mobile nice" the CEO asked for, and it's **CSS-only**.
3. **🟡 Token drift** — the page violates the locked design system in several places (`rounded-3xl`, `p-7`, `text-3xl` names, `text-[10px]` in `section.tsx:36`, `opacity-60` on disabled cards = contrast fail, a non-existent `tabular-num` class at lines 230/235). Cheap to fix while redesigning.
4. **⚔️ One genuine decision for the CEO** — you asked for a Playland/ClawFleet-style **bottom-nav**, but the team recommends *against* a bottom-nav with a "โปรแกรม" tab on a launcher page (reasoning in §8). This is the only thing the audit can't auto-decide.

**Audience reality (important):** `/home` redirects driver/staff/branch_manager/area_manager away (`page.tsx:47-74`). The only roles that see this screen are **super_admin · org_admin · admin · viewer(program-admin)**. So we design for the **owner/admin on a phone**, not field staff.

```tsx
{canSee("ledger") && (
  <ModuleCard slug="ledger" enabled={moduleEnabled.ledger ?? true} landingPath="/ledger" />
```

```
│ └─────────┘                  │
│ ปฏิบัติการสาขา  (5 tiles…)   │
└─────────────────────────────┘   ~6 tiles + 2 group headers visible
```

**Module tile anatomy (2-col, ~165×96px — ~6× denser than current):**
- Whole tile = `<Link>`, `rounded-2xl border bg-white p-4 shadow-sm`, min 44px tap target.
- Row 1: emoji glyph in `size-10 rounded-xl bg-[var(--color-brand-50)]` chip (`aria-hidden`) + small leaf-green status **dot** top-right (not a Badge pill).
- Row 2: name `text-base font-semibold`. Row 3: tagline `text-xs text-zinc-500 line-clamp-1`.
- `aria-label` on the Link starts with the **module name** (not emoji) — WCAG 4.1.2.
- Disabled = real `text-zinc-400 bg-zinc-50` (NOT `opacity-60`, which fails contrast).
- Dropped vs current: size-14 emoji box, blur blob, `<Badge>`, `text-3xl` name, `min-h-[60px]` desc, "เข้าโปรแกรม →" footer.

**5 wireframed states** (full ASCII in `/tmp/audit_hub_phase2_ux.md`): admin default · admin+pending strip · viewer-flat-3 · viewer-empty · optional bottom-nav.

**Visual mockup:** `/tmp/audit_hub_mockup.html` (standalone, open in a browser — phone-frame preview of the whole redesign with the ระบบบัญชี tile emphasized).

## §6 · Token & a11y fixes (apply during redesign)

| # | Violation (file:line) | Fix | WCAG/token |
|---|---|---|---|
| 1 | `rounded-3xl` cards (page.tsx:483) | `rounded-2xl` | radius scale |
| 2 | `p-6 sm:p-7` (page.tsx:483) | `p-4` (tile) | spacing scale (no p-7) |
| 3 | `text-2xl sm:text-3xl` name (page.tsx:519) | `text-base/lg` | density |
| 4 | `text-[10px]` (section.tsx:36) | `text-[11px]` | WCAG 1.4.4 |
| 5 | `opacity-60` disabled card (page.tsx:488) | real `text-zinc-400 bg-zinc-50` | WCAG 1.4.3 |
| 6 | footer `text-zinc-400` (page.tsx:453) | `text-zinc-500` | WCAG 1.4.3 |
| 7 | `tabular-num` (page.tsx:230,235) — not a real class | `tabular-nums` | bug |
| 8 | card link name starts with emoji glyph (page.tsx:504,553) | `aria-hidden` emoji + `aria-label` on Link | WCAG 4.1.2 |
| 9 | no `<main>` landmark / skip-link | add `<main>` + `aria-labelledby` on sections | WCAG 2.4.1 / 1.3.1 |
| 10 | "โปรแกรมเปิดอยู่ X/Y" denominator = org_modules rows (page.tsx:440-443) | base on MODULES count | data-truth |
| 11 | "2 บริษัท" hardcode (page.tsx:228) | dynamic or confirm constant | data-truth |

Strengths to keep (A11Y verified PASS): decorative blobs already `aria-hidden`; global `prefers-reduced-motion` block (globals.css:515); global `*:focus-visible`; 16px inputs; h1→h2→h3 hierarchy.

## §8 · Top decisions needing CEO eyes (highest blast radius)

1. **Bottom-nav: build it or not?** — owner: IA/UX/DEVIL split · cost-if-wrong: med
   - You asked for a Playland/ClawFleet-style bottom-nav. The team's concern: this is a **launcher** page — the card grid *is* the navigation. A "โปรแกรม" tab would recreate the exact "two-paths-to-the-same-page" the team deliberately removed before (`page.tsx:448` comment). Also `viewportFit:'cover'` is held project-wide (`app/layout.tsx:64`) so iOS safe-area = 0 → a bottom-nav floats over the home-indicator until that ships; and the AI-chat button (`z-30 bottom-4`) overlaps.
   - **Recommended default:** ⛔ **No bottom-nav on the hub** — the compact hero + dense grouped grid already fixes the scroll problem and every program is ≤2 taps. *If* you still want the phone-app feel → a **3-tab** variant (หน้าหลัก/งานรอ/ฉัน, **no** "โปรแกรม" tab) + ship `viewportFit:'cover'` first. ☐ approve no-nav / ☐ build 3-tab variant / ☐ build 4-tab incl. โปรแกรม
2. **Pinned "ใช้บ่อย" row?** — owner: OWN/DEVIL · cost-if-wrong: low
   - **Recommended:** ✅ Wave 1 = a **static** sensible top-4 row (no DB). True per-user favorites (remembers each person's pins) needs a DB table → defer. ☐ static row / ☐ skip / ☐ full DB favorites
3. **Keep program emoji or switch to Lucide icons?** — owner: OWN/UX/DEVIL · cost-if-wrong: low
   - **Recommended:** ✅ Keep emoji as the module's brand glyph (memorable, registry-driven), just make them accessible; use Lucide for status/buttons. ☐ keep emoji / ☐ all Lucide
4. **Fix the "1,039 รายการรออนุมัติ" banner on mobile?** — owner: OWN · cost-if-wrong: med
   - It's the most prominent thing in your screenshot but lives in a different component. **Recommended:** ✅ include in Wave 1 — show the 💰/👤 breakdown on mobile + don't dismiss-for-the-whole-day if items remain. ☐ Wave 1 / ☐ Wave 2 / ☐ leave as is
5. **Grouping vs flat grid?** — owner: IA/DEVIL · cost-if-wrong: low
   - **Recommended:** ✅ 3 groups for owner/admin, flat for sparse viewers. ☐ grouped / ☐ flat
