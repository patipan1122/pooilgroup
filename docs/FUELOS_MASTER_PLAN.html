📝 ร่าง v0.3 · โปรแกรมแยกเดี่ยว (คนละแอป/คลัง/deploy) · ก๊อปโค้ดเดิมเป็นต้นแบบ

🎯 ภาพใหญ่ที่คุณต้องการ

ลูกค้าน้ำมันส่วนใหญ่ ทักเข้ามาทาง LINE กลุ่ม (สั่งของ · ส่งสลิปโอน · ถามราคา · แจ้งทะเบียนรถมารับ) → หน้าทำงานหลักจึงต้องเป็น "กล่องรวมแชท" ที่พนักงานทุกคนนั่งตอบร่วมกันในที่เดียว แล้วทำงานต่อได้ครบ (ออกใบราคา · ผูกลูกค้า · ส่งของ) + มีรายงานว่าใครตอบเร็ว/ช้า/ลูกค้าถามแล้วไม่มีคนตอบ

ปัญหาเดิม
แชทกระจัดกระจายหลายกลุ่ม LINE · ไม่รู้ใครตอบใครยัง · ลูกค้าถามแล้วตกหล่น · สลิป/ออเดอร์/ราคา ปนกันในแชท
หลังมีระบบ
ทุกแชทรวมจอเดียว · เห็นสถานะ "ตอบแล้ว/ค้าง" · กดออกใบเสนอราคาในแชท · บอทช่วยตอบ · รายงานคนตอบเร็ว/ช้า + ลูกค้าที่ตกหล่น

🧱 เป็นโปรแกรมแยกเดี่ยว · ก๊อปโค้ดเดิมเป็นต้นแบบ

โปรแกรมขายส่งน้ำมันนี้ แยกขาดจากระบบ Pool 100% — คนละแอป คนละฐานข้อมูล คนละ deploy · แต่เรา ก๊อป "โค้ด/สูตร" ของเดิมมาเป็นต้นแบบ เพื่อสร้างเร็วขึ้น (ก๊อปโค้ด ≠ แชร์ข้อมูล)

ส่วนของระบบเริ่มยังไง
โครงแอป + ระบบล็อกอิน + ดีไซน์ (UI kit)ก๊อปต้นแบบ
ระบบแชทรวม (Inbox engine)ก๊อปต้นแบบ + เพิ่มรับกลุ่ม
บอทตอบอัตโนมัติ + สรุปรายวันก๊อปต้นแบบ
16 ตารางขายน้ำมัน + GPSก๊อปต้นแบบ
ฐานข้อมูลใหม่ (Supabase) — เปล่า เริ่มเก็บของตัวเองตั้งใหม่
CRM ผูกลูกค้า + รายงานเวลาตอบ + ออกใบราคาในแชทสร้างใหม่
💡 ผลคือ: ได้โปรแกรมของตัวเองสะอาด ๆ ไม่ปนเมนูอื่น · ข้อมูลอิสระไม่เชื่อม Pool · แต่ไม่ต้องเขียนทุกอย่างใหม่ตั้งแต่ศูนย์

< 1 วิเปิดกล่องแชท
ทันทีข้อความใหม่เด้งเข้า (realtime)
< 0.3 วิกดตอบ/ออกใบราคา
0แชทตกหล่น
  • Realtime push — ข้อความเข้าเด้งทันทีไม่ต้องรีเฟรช (ใช้ Supabase Realtime)
  • โหลดเฉพาะแชทที่เปิด + เลื่อนค่อยโหลดเพิ่ม (ไม่ดึงพันแชทพร้อมกัน)
  • นับ "ค้างตอบ" ไว้ล่วงหน้า (unreadCount) — ไม่ต้องคำนวณใหม่ทุกครั้ง
  • Render ที่ server + โหลด JS น้อย + index ครบ ไม่มี N+1 (บทเรียนเดิมของ Pool)
  • กดแล้วเห็นผลทันที (Optimistic) — พิมพ์ตอบ/ออกใบราคา เด้งเลย

🟥 ความจริงเรื่อง LINE ที่ต้องเข้าใจก่อนเริ่ม

  • ดึงแชทเก่าย้อนหลังไม่ได้ — LINE ไม่มี API ให้ดึงประวัติ · เราจะ เริ่มเก็บตั้งแต่วันเชื่อม เป็นต้นไป (ของเก่ายังเปิดดูใน LINE ได้ปกติ แค่ไม่เข้าระบบเรา)
  • ต้องเพิ่มโค้ดรับ "ข้อความกลุ่ม" — ปัจจุบันระบบรับแค่แชท 1:1 · กลุ่มที่ลูกค้าใช้ต้องเพิ่มการรับ (groupId)
  • ต้องมีกุญแจ LINE OA ของ PO Oil (Channel Access Token + Secret) + ตั้ง Webhook URL ใน LINE Developers → ข้อความถึงจะไหลเข้าระบบ
  • ระบุพนักงานด้วย LINE userId — เพื่อให้รู้ว่า "ใครตอบ" ในกลุ่ม ต้องจับคู่ userId ของพนักงาน 1 ครั้ง
  • OA ต้องอยู่ในกลุ่ม + เปิดสิทธิ์ให้บอทรับข้อความกลุ่มได้ (ตั้งค่าใน LINE)
💡 "เชื่อม LINE ก่อน" = พอตั้งค่าเสร็จ ข้อความใหม่จะเริ่มไหลเข้า DB → ผมอ่าน/ทำงานกับข้อมูลจริงได้ → ต่อยอด CRM/รายงาน/ใบราคา ได้แม่นยำ

1. กุญแจ LINE OA: ขอ Channel Access Token + Channel Secret ของ PO Oil OA (อยู่ใน LINE Developers Console) — ผมต้องใช้เชื่อม · หาให้ไหม หรือให้ผมแนะวิธีหา?
2. กลุ่มลูกค้า: OA ของ PO Oil อยู่ในกลุ่มลูกค้าครบทุกกลุ่มแล้วใช่ไหม? (เห็นในรูปว่าอยู่หลายกลุ่ม) มีกี่กลุ่มประมาณ?
3. ระบุพนักงาน: พนักงานที่ตอบในกลุ่มมีกี่คน? เดี๋ยวเราจับคู่ LINE ของแต่ละคน 1 ครั้ง เพื่อให้รายงาน "ใครตอบ" แม่น
4. บอท: อยากให้บอทตอบอัตโนมัติเรื่องอะไรบ้าง (เช่น ราคาวันนี้ · เลขบัญชีโอน) หรือช่วงแรกขอแค่ "เก็บแชท + ให้คนตอบ" ก่อน?
5. รายงานเวลาตอบ: นับ "ช้า" ที่กี่นาที? (เช่น เกิน 30 นาทีไม่มีคนตอบ = แดง)
