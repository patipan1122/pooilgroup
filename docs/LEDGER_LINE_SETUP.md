## สิ่งที่สร้างเสร็จในรอบนี้ (อยู่บน branch แล้ว)

1. **หลายรูปในครั้งเดียว** — ส่งใบเสร็จ 4-5 รูปรวด → สรุปเป็น **การ์ดเดียว (carousel)**
   ปัดดูทีละใบ กดแก้ไขแต่ละใบได้ (รูปเดียวยังตอบไว เหมือนเดิม).
2. **ฟอร์มแก้ไขละเอียดแบบ Bainy** — 4 ส่วน: ข้อมูลร้าน/เอกสาร · รายการ+ยอดเงิน (แก้
   รายการสินค้าได้) · การชำระเงิน/ผู้เบิก · หมายเหตุ/หลักฐาน. เก็บ ประเภทเอกสาร ·
   เลขที่เอกสารร้าน · ที่อยู่ · ส่วนลด · สถานะจ่าย · ผู้เบิก · รายจ่ายประจำ.
3. **Rich Menu** — เมนู 6 ปุ่มในแชต LINE (ปุ่มเดียวติดตั้งจากหน้า /ledger/settings).
4. **ลิงก์เชิญพนักงานแบบกำหนดสิทธิ์** — ระบุสาขา/บทบาท · เปิดใน LINE เข้าร่วมได้เลย.
5. **สรุปรายวัน + เตือนงบ** — บอท DM หา CEO/บัญชี (ไม่กวนกลุ่มสาขา).
6. **Google Drive** — เก็บต้นฉบับใบเสร็จอัตโนมัติ โฟลเดอร์ **เดือน → สาขา → หมวด**
   พร้อมลิงก์แชร์ให้สำนักงานบัญชี (ทำงานเมื่อใส่ env ด้านล่าง).
7. **มาสคอตน้องใบเสร็จ** — แสดงอารมณ์ตามผล (ดีใจ/สงสัย/เตือน) บนการ์ด + เว็บ.

## ✅ ขั้นที่คุณต้องทำเอง (เรียงตามลำดับ)

### 1) Apply migration ที่ฐานข้อมูล prod (2 ไฟล์)
```
supabase/migrations/20260603210000_ledger_line_phase2.sql   (ถ้ายังไม่ลง)
supabase/migrations/20260604120000_ledger_phase3.sql        (ใหม่รอบนี้)
```
ลงผ่าน `supabase db push` หรือ Supabase SQL editor. ทั้งคู่ idempotent (ลงซ้ำได้).
phase3 เพิ่ม: คอลัมน์แบบ Bainy บน `ledger_expense` + ตาราง `ledger_capture_batch`
(บัฟเฟอร์รวมรูปหลายใบ).

### 2) Deploy (merge branch → setup)
อนุมัติให้ผม merge `claude/ledger-line-bainy-parity` → `setup` (Pool prod auto-deploy).
⚠️ ก่อน merge ผมจะ `git fetch` + รวม `origin/setup` เข้า branch ก่อน (กันเคส
branch ตามหลัง prod — ตาม memory `branch-off-stale-origin-setup-revert-trap`).

### 3) ตั้งเมนูในแชต LINE
หลัง deploy → เปิด **/ledger/settings** → การ์ด "เมนูในแชต LINE" → กด **ติดตั้งเมนู**
(ใช้ token ที่เชื่อมไว้แล้ว — ปุ่มเดียวจบ).

### 4) (ถ้าจะเปิด Google Drive) ตั้ง env ใน Vercel prod
```
LEDGER_DRIVE_CLIENT_ID=...
LEDGER_DRIVE_CLIENT_SECRET=...
LEDGER_DRIVE_REFRESH_TOKEN=...        # OAuth ของบัญชี Google ที่จะเก็บไฟล์
LEDGER_DRIVE_ROOT_FOLDER_ID=...       # id โฟลเดอร์ "ระบบบัญชี2027" (ไม่ใส่ = root)
LEDGER_DRIVE_PUBLIC_LINKS=1           # (optional) แชร์ลิงก์แบบ anyone-with-link
```
ถ้าไม่ใส่ ระบบทำงานปกติทุกอย่าง — แค่ไม่เก็บเข้า Drive (ไฟล์อยู่ R2 เหมือนเดิม).

### 5) เชิญพนักงาน
/ledger/settings → "เชิญพนักงานเข้าระบบ" → เลือกสิทธิ์ + สาขา → สร้างลิงก์ → ส่งให้
พนักงานเปิดใน LINE. คนที่เป็น **บัญชี/แอดมิน** จะได้รับสรุปรายวันอัตโนมัติ.

### 6) หมุน secret ที่เคยพิมพ์ในแชต
LINE Channel Secret / Access Token ที่เคยส่งมาในแชต — แนะนำหมุนใหม่หลังตั้งค่าเสร็จ.
