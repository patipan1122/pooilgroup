# Playland Agent — โปรแกรมตัวกลาง รันบนคอมร้าน

เชื่อมเครื่องอ่านหน้า ACS-F606 (วง LAN ร้าน) เข้ากับเว็บ pooilgroup-web จริง (Vercel/HTTPS)
โดยไม่ต้องเปิด proxy/bridge สาธารณะ — เพราะ agent อยู่วงเดียวกับเครื่อง คุยกันได้ตรง (HTTP)
แล้วค่อยส่งต่อเข้าเว็บแบบ HTTPS ได้เอง (คนละปัญหากับ firmware เครื่องที่ทำ HTTPS ไม่ได้)

## วิธีรัน

1. `cd playland-agent`
2. คัดลอก `.env.example` → `.env` แล้วใส่ค่าให้ตรงเครื่องจริง (IP, webhookSecret ของแต่ละเครื่อง)
3. `npm start` (ไม่ต้อง `npm install` — ใช้แค่ของในตัว Node.js 20+)
4. ต้องเห็นบรรทัด `🚀 playland-agent ฟังอยู่ที่ http://<ip>:8080 (2 เครื่อง)` และ `🔗 [...] ผูก callback ✅` ทั้ง 2 เครื่อง

## ทำงานยังไง

- **เครื่อง → เว็บ:** เครื่องสแกนหน้าเสร็จ → ส่ง log มาที่ agent (LAN, HTTP) → agent ส่งต่อเข้า
  `/api/playland/acs/event` จริงแบบ HTTPS → เอาคำตอบจากเว็บส่งกลับเครื่อง (รวมคำสั่งเปิดประตูของ QR ด้วย)
- **เว็บ → เครื่อง:** ลูกค้าลงทะเบียนหน้าจากมือถือ → เว็บสร้างคิวไว้ (`PlaylandFaceSync`) →
  agent มาถามคิวทุก 5 วิ (`/api/playland/acs/agent/face-sync`) → เอาไปเพิ่ม/ลบที่เครื่องจริงผ่าน LAN
  → รายงานผลกลับเว็บ (`/api/playland/acs/agent/face-sync/result`)

## รันทิ้งไว้ตลอด (production)

```bash
npm i -g pm2
pm2 start agent.js --node-args="--env-file=.env" --name playland-agent
pm2 save
pm2 startup   # ให้เริ่มเองตอนคอมเปิดเครื่อง
```

## ยังไม่ทำ (รู้ไว้)

- คำสั่ง "เปิดประตูฉุกเฉิน" จากหน้าเว็บ (`gate-override.ts`) ยังไม่ต่อผ่านคิวแบบนี้ —
  ตอนนี้ถ้าเว็บเรียกเครื่องตรงไม่ติด (LAN ไม่ถึง) จะแค่บันทึก log ไว้ ต้องให้พนักงานกดเปิด
  ที่เครื่อง/บอร์ดประตูเองแทน (มีปุ่มจริงอยู่แล้ว) — ยังไม่กระทบ MVP นี้ เป็นงานต่อยอด
